# 카드뉴스·블로그 이미지 점검

우드엔조이(네이버 cafe_peanut, 인스타, 스레드)와 myinfobay용 이미지를 **사용자에게 보여주기 전에** 이 점검을 모두 통과시킨다. 통과하지 못한 장이 있으면 고친 뒤 처음부터 다시 점검한다. "대충 괜찮아 보인다"는 통과가 아니다.

콘텐츠 스튜디오(woodenjoy-autopilot)도 같은 규칙으로 돌아간다: tools/render_cards.js가 아래 자동 검사를, engine/generate.py의 카드 눈 검사가 A/B/C의 눈 검사 항목을 맡는다. 이 스킬을 바꾸면 스튜디오도 같이 바꾸자고 말한다.

## 기본 규격 (따로 말이 없으면)
- 인스타 카드: 1080×1350(4:5). Meta 게시 API가 받는 가장 긴 세로 비율이다(허용 범위 4:5~1.91:1). 3:4(1080×1440)는 앱에서는 올릴 수 있지만 API로는 거절되므로 쓰지 않는다
- 프로필 그리드는 표지를 3:4로 보여주나 좌우가 조금(약 34px씩) 잘린다. 표지 핵심 글자는 가운데에 둔다
- 캐러셀은 모든 장이 같은 비율이어야 한다(첫 장 비율을 따름), JPEG, 장당 8MB 이하
- 글자는 좌우 70px 안쪽, 맨 아래 130px는 계정명(@우드엔조이) 자리
- 색: 배경 #EDF4F1, 제목 #1F4F3F, 강조 #2F6B57, 연주황 #F6E2BF·#FBF3E4, 본문 #1D2421
- 글꼴 한 가지(본고딕/Noto Sans KR) · 제목 90~104px · 부제 48px · 그림 속 라벨을 포함해 **실제 표시 크기 36px 미만 금지**
- 장마다 같은 틀(상단 "WOOD & JOY · 셀프 집수리" + 쪽번호, 제목, 부제, 그림/내용, 계정명)

## 점검 항목

### A. 내용이 맞는가 (가장 중요)
1. **그림과 제목·라벨이 같은 것을 말하는가.** 예: "아웃도어" 장의 그림은 문이 옆판 앞면을 덮고 있어야 하고, "인도어" 그림은 문이 옆판 사이에 들어가 옆판 앞면이 보여야 한다. 그림을 말로 다시 설명해 보고 제목과 맞는지 확인한다
2. 부품 모양이 실제와 맞는가 (예: 싱크대에는 일자 문경첩이 아니라 35파이 컵이 달린 숨은 경첩)
3. 용어가 쇼핑몰 상품명에서 확인한 소비자 용어인가 (블로그 스킬의 용어 확인 단계와 같은 말을 쓴다)
4. 블로그 글·캡션과 내용이 어긋나지 않는가 (예: 마지막 장에 "개수는 블로그에"라고 썼는데 글에 개수 내용이 없으면 불합격)
5. 표지에 약속한 개수(예: 5가지)와 실제 장 수가 맞는가
6. AI가 만든 그림은 정확하지 않을 때가 많다. 구조를 설명하는 그림(단면·위치·치수)은 도형으로 직접 그린다

### B. 글자
7. 오타·띄어쓰기 (예: 경철→경첩, 거내→꺼내, 씬크→씽크, 우리집→우리 집). 글자를 한 자씩 읽는다
8. 글자가 틀·박스·그림 밖으로 넘치거나 잘리지 않는가
9. 의도하지 않은 줄바꿈이 없는가 (제목이 한 글자만 다음 줄로 넘어가는 것 등)
10. 모든 글자가 휴대폰에서 읽히는 크기인가 (실제 표시 36px 이상)
11. 글자가 그림·다른 글자와 걹치지 않는가

### C. 구성
12. 빈 칸·빈 박스·내용 없는 장이 없는가 (Canva가 만드는 빈 페이지 포함)
13. 장 순서가 맞는가 (Canva가 순서를 뒤집어 만드는 경우가 있음)
14. **같거나 비슷한 내용·그림이 반복되는 장이 없는가.** 장마다 새 정보 하나 + 다른 형태의 그림(정면도 / 위에서 본 그림 / 상품명 풀이 / 치수 / 순서 / 아이콘 목록)
15. 장마다 글꼴·글자 크기·여백·색이 같은 규칙을 따르는가
16. 아래쪽에 너무 큰 빈 공간이 없고, 본문이 계정명 자리를 침범하지 않는가
17. 표지 1장만 보고도 주제가 보이고(핵심 글자는 가운데), 마지막 장에 행동 안내(저장·보내기·블로그 중 하나)가 있는가

## 점검 방법
1. **자동 검사** (코드를 돌릴 수 있는 환경): 카드를 HTML/SVG로 만들고 Playwright로 렌더링한 뒤 아래를 코드로 확인한다
   - 모든 글자의 실제 표시 크기(SVG는 확대·축소 비율까지 계산) ≥ 36px
   - 글자 상자가 좌우 여백·그림 틀·계정명 자리를 넘지 않음, 가로 넘침 없음
   - 제목·부제의 줄 수가 의도한 줄 수와 같음
   - 블록끼리 걹침 없음, 빈 칸 없음, 아래 빈 공간 260px 이하
   - 장끼리 32×43으로 줄여 비교해 너무 비슷한 쌍과, 여러 장에 반복된 문장을 찾음
   - 이미지 크기가 1080×1350인지
2. **눈 검사** (항상): 8장을 한 장에 모은 "전체보기" 이미지를 만들어 보고, 그다음 장마다 크게 본다. A의 1·2·4·5번과 C의 14번은 코드로 잡을 수 없으므로 반드시 눈으로 확인한다. 글자와 도형이 걹치는 것도 눈으로만 잡힌다
3. **Canva로 만든 경우**: read-design으로 장마다 썸네일과 글자를 모두 받아 위 항목을 확인한다. 썸네일이 안 나오면 편집 모드를 열어 다시 받는다. Canva 디자인 크기도 1080×1350으로 만든다. Canva가 만든 그림 수정으로도 A항목이 안 맞으면, 고쳐 쓰지 말고 직접 만드는 방식(1번)으로 다시 만든다
4. 문제가 나오면 고치고 1번부터 다시. 자동 검사 0건 + 눈 검사 통과가 될 때까지 반복한다

## 보고 형식
사용자에게 이미지를 보여줄 때 한국어로 짧게 함께 적는다.
- 자동 검사 결과 (문제 수, 고친 것)
- 눈 검사에서 고친 것
- 확신이 없는 부분이 있으면 숨기지 말고 적는다 (예: "15T·18T는 판매처마다 기준이 달라 모호하게 썼어요")
