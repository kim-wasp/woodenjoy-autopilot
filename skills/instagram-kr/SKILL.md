# 한국어 인스타 글쓰기 (사장님 계정 전용)

인스타는 표지 한 장으로 멈추게 하고, 넘기게 만들고, 저장하거나 친구에게 보내게 하는 게 전부다.
이 스킬은 내용(구성, 문구, 캡션, 대본)을 담당한다. 카드 이미지를 만들었으면 보여주기 전에 card-image-check 스킬로 반드시 점검한다.
콘텐츠 스튜디오(woodenjoy-autopilot)도 같은 규칙으로 돌아간다. 이 스킬을 바꾸면 스튜디오도 같이 바꾸자고 말한다.

## 1. 사장님 고정 규칙

1. 후킹이 가장 중요하다. 표지, 캡션 첫 줄은 세게 쓴다.
2. 단, 사실만 쓴다. 근거 없는 주장, "무조건", "100%" 같은 과장, 지어낸 경험담은 넣지 않는다. 우드엔조이는 지금 수주 중이 아니므로 특정 실제 시공을 지어내지 않는다. 사장님이 준 이야기만 경험으로 쓴다.
3. 용어는 사람들이 실제로 쓰는 말로. 시공자 용어와 소비자 용어를 구분하고, 제품명은 쇼핑몰 상품명으로 확인한다.
4. 말투: 따로 말이 없으면 친근한 해요체. 사장님이 계정별 말투를 정하면 그걸 따른다.
5. 쿠팡 파트너스 등 제휴 링크는 캡션에 넣지 않는다(캡션 링크는 눌리지 않음). 프로필 링크로 안내한다.

## 2. 계정별 설정

1. woodenjoy00 (우드엔조이): 목공, 가구, 셀프 집수리, 경첩 같은 부자재, 공구. 저장해두고 쓸 때 꺼내보는 정보 카드가 중심. 구조를 설명하는 그림(단면, 위치, 치수)은 AI 그림 말고 도형으로 직접 그린다.
2. infobay_kr (상식): 생활 상식, 사회 통념, 커먼센스 앱 투표 주제. 친구에게 보내고 싶어지는 논쟁, 반전 카드가 중심.
3. 다른 계정이 생기면 여기 한 줄 추가한다.

## 3. 인스타 사실 (2026-11 웹 확인)

1. 캡션 최대 2,200자. 피드에서는 앞 125자 안팎만 보이고 나머지는 더 보기로 접힌다(기기에 따라 더 짧을 수 있음).
2. 해시태그는 글 하나에 최대 5개(2025년 12월부터). 캡션과 댓글을 합친 개수다. 댓글에 더 다는 꼼수는 통하지 않는다.
3. 카드 크기는 1080x1350(4:5)로 통일한다. Meta 게시 API가 받는 가장 긴 세로 비율이다(허용 4:5~1.91:1). 3:4(1080x1440)는 앱에서만 올릴 수 있고 API로는 거절된다. 프로필 그리드는 표지를 3:4로 좌우를 조금 잘라 보여주므로 표지 핵심 글자는 가운데에 둔다. 캐러셀은 최대 20장, 보통 6~10장이 끝까지 읽힌다.
4. 인스타 책임자(모세리)가 밝힌 가장 중요한 신호 3가지: 시청/체류 시간, 도달 대비 좋아요, 도달 대비 보내기(DM 공유). 보내기는 팔로워가 아닌 사람에게 퍼지는 데 특히 중요하다. 캐러셀은 넘겨 보는 시간과 저장이, 릴스는 시청 시간과 새 사람 도달이 강하다.
5. 원본 콘텐츠를 우대하는 방향이다. 남의 카드를 바꿔 올린 티가 나면 안 된다.

이 사실은 바뀔 수 있다. 사장님이 다르다고 하거나 오래돼 보이면 다시 검색해서 확인하고 이 칸을 갱신하자고 말한다.

## 4. 카드뉴스 구성 고르기

내용에 맞는 구성을 하나 고르고, 무엇을 골랐는지 한 줄로 알린다. 구성 선택이 문구를 다듬는 것보다 중요하다.

1. 모음형 (도구, 제품, 팁 목록): 표지에 정확한 개수와 얻는 것(예: "경첩 살 때 확인할 것 5가지"). 한 장에 하나씩. 표지에 약속한 개수는 정확히 채운다. 개수 부풀리려고 빈 장 넣지 않는다.
2. 실수 바로잡기형 (흔한 실수가 있는 주제): 표지에 "대부분 이렇게 해서 망함" 같은 반전 → 왜 틀렸는지 → 방법마다 이름 붙여 한 장씩(✕ 이렇게 / ○ 이렇게) → 한 줄 정리.
3. 순서형 (수리, 설치 방법): 표지에 완성 결과 → 무엇이 문제였는지 → 전체 단계 수와 걸리는 시간을 먼저(예: "4단계, 20분") → 단계마다 한 장 → 결과.
4. 비교형 (A와 B 중 뭐가 나은지): 표지에 질문 → 기준마다 한 장 → "이런 집은 A, 이런 집은 B" 결론. 반드시 하나를 고르거나 기준을 분명히 준다.
5. 논쟁형 (infobay 사회 통념): 표지에 논쟁 질문 → 양쪽 입장 → 실제 데이터나 투표 결과(있을 때만) → "너는 어느 쪽?" 대신 커먼센스에서 투표해보라는 안내. 한쪽을 조롱하지 않는다.

## 5. 장별 규칙

1. 표지(1장)는 혼자서도 피드에서 멈추게 해야 한다. 표지만 보고도 주제가 보여야 한다. 표지 후킹 후보 3개(반전/실수/숫자/장면/질문/비교 중 서로 다른 패턴)를 만들어 사장님이 고르게 한다.
2. 표지 끝에 다음 장을 넘기게 만드는 열린 고리를 둔다(답은 안에 있음).
3. 장마다 새 정보 하나. 한 장에 설명이 두 문장 넘게 필요하면 두 장으로 나눈다. 비슷한 장 반복 금지.
4. 숫자는 무엇의 수치인지 같은 장에 적는다.
5. 안쪽 장은 모두 같은 틀(배치, 글자 크기, 색). 바뀌는 건 내용뿐.
6. 마지막 장은 행동 하나만: 저장(쓸 때 꺼내보기) 또는 보내기(이 고민 있는 친구에게) 또는 프로필 링크. 세 개를 한꺼번에 요구하지 않는다.
7. 글자는 휴대폰에서 읽히는 크기로. 글자 양을 줄이는 쪽으로 고친다.

## 6. 캡션

1. 첫 줄(60자 이내): 후킹 + 주제 핵심어. 표지 문구를 그대로 반복하지 말고 다른 각도에서 다시 건드린다. 앞 125자 안에 읽을 이유가 다 들어가야 한다.
2. 핵심 2~4줄: 카드를 안 넘겨도 얻는 요점, 또는 카드에 없는 덧붙임 한두 가지. 검색에 걸릴 말(제품명, 증상, 장소)을 자연스럽게 넣는다.
3. 행동 안내 한 줄: 저장 또는 보내기 중 하나. 자세한 글이 있으면 "프로필 링크에 있어요".
4. 해시태그 3~5개, 맨 끝에. 넓은 것 1개 + 구체적인 것 2~4개(예: #셀프인테리어 #싱크대경첩 #경첩교체). 내용과 상관없는 인기 태그 금지.
5. 반응 낚시 금지: "댓글에 YES 남겨주세요", "공감하면 좋아요", "맞팔". 진짜 궁금한 질문 하나는 괜찮다.

## 7. 릴스 대본 (요청할 때)

1. 첫 3초: 화면 글자 + 말로 후킹 하나. 소리 없이 봐도 알 수 있게 자막을 넣는다. 인사, 자기소개로 시작하지 않는다.
2. 본문: 장면 하나에 정보 하나. 15초 안팎이면 핵심 하나만.
3. 끝: 처음 후킹의 답을 꼭 주고 끝낸다. 다시 보게 만드는 마무리(처음 장면과 이어지기)는 좋다.
4. 화면은 세로 9:16(1080x1920).
5. 출력: 장면 번호 / 초 / 화면에 보일 것 / 자막 / 내레이션.
6. 음악은 인스타 앱에서 넣는다고 안내한다(저작권).

## 8. AI 티 점검 (내기 전에 반드시)

1. "X가 아니라 Y예요" 대구 뒤집기 → Y를 바로 말한다.
2. "~도 없고 ~도 없고" 부정 나열.
3. "결과는? ~", "핵심은: ~" 혼자 묻고 답하기.
4. "이제 걱정 끝", "꿀팁 대방출", "총정리", "알아보아요" 같은 상투어와 결산하는 마무리.
5. 줄마다 이모지로 시작하기, 이모지 남발(캡션 전체 3개 이하).
6. 대시(—). 쉼표나 줄바꿈으로.
7. 근거 없는 감정 연출.

## 9. 작업 순서

1. 주제와 계정 확인. 블로그 글을 주면 그중 저장하거나 보낼 만한 부분만 뽑는다(글 전체를 카드로 자르지 않는다).
2. 사실/용어/제품명을 웹에서 확인한다.
3. 구성 선택(4번) → 표지 후보 3개 → 장별 문구 → 캡션 → 해시태그.
4. 8번 AI 티 점검, 표지에 약속한 개수와 실제 장 수가 맞는지, 캡션 글자 수, 해시태그 개수 점검.
5. 이미지를 만들었으면 card-image-check로 점검한 뒤 보여준다.

## 11. 업로드

사장님이 올려달라고 하면 올리기 전에 계정, 카드 이미지, 캡션 최종본을 보여주고 확인받는다. 확인 없이 올리지 않는다. 콘텐츠 스튜디오에서 만든 글은 스튜디오 승인 화면에서 승인하면 예약 시간에 올라간다.
