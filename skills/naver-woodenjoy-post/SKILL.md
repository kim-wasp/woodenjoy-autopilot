# 네이버 우드엔조이 글쓰기 (검색 + 홈피드)

목표: 네이버 검색과 **홈피드(홈판)**에서 **클릭되고 끝까지 읽히고 반응이 달리는 글**. 애드포스트가 붙어 있으므로 유입과 체류가 곧 수익이다. 블로그는 2013년부터 운영된 우드엔조이(원목가구 제작·생활목공) 블로그이고, 지금은 "셀프 집수리" 카테고리로 재가동 중이다.

홈피드는 네이버 앱 검색홈 아래의 AI 개인화 추천이다. 노출 기준은 공개되지 않았고, 확인된 것은 관심사·이웃 관계·활동 이력 기반 추천이라는 점이다(2025.9 네이버 발표). 그래서 우리가 움직일 수 있는 신호는 세 가지다: **썸네일·제목 클릭률, 체류시간, 반응(공감·댓글)**. "2,000자 이상", "키워드 15회" 같은 출처 없는 공식은 따르지 않는다.

사용자가 "네이버 글 써줘: 주제"처럼 한 줄만 말해도 아래 0~9단계(2-1 용어 확인 포함)를 끝까지 진행한다. 중간에 묻지 않는다.

## 0. 경쟁 글 분석 (가능할 때만)
**naver-blog-research 스킬을 쓸 수 있는 환경(Claude Code 등)이면 반드시 먼저 실행한다.**
- 메인 키워드로 네이버 블로그 상위 글 약 10개를 검색해 본문까지 읽는다. 가벼운 조사 용도로만, 한 번에 10개 안팎
- 정리할 것: 제목 패턴(어떤 단어·숫자·공식을 쓰는지), 대략적 글자 수, 소제목 구성, 표·이미지 사용, **상위 글들이 공통으로 빠뜨린 내용**
- 이 분석으로 "상위 글보다 더 구체적이고, 빠진 내용을 채운" 제목과 구성을 정한다. 경쟁 글 문장을 베끼지 않는다
- 분석 결과는 출력 맨 앞에 5줄 이내로 요약한다
- uplika 도구(check_naver_visibility, research_naver_keywords)를 쓸 수 있으면 메인 키워드의 검색 노출·AI 브리핑 여부를 함께 확인해 요약에 한 줄 넣는다

이 스킬을 쓸 수 없는 환경(Claude 앱 대화 등)이면 이 단계를 건너뛰고 "경쟁 글 분석: 이 환경에서는 생략"이라고 한 줄 적은 뒤 바로 1단계로 간다. 네이버 페이지를 다른 방법으로 우회 접속하려 하지 않는다.

## 1. 입력 정리
사용자에게 받은 것을 먼저 정리한다. 없는 것은 묻지 말고 아래 기본값으로 진행한다.
- 주제 (글감 리스트의 제목이나 키워드)
- 사진 유무: 대부분 **없음**이 기본(현재 작업 사진 없음). 사진이 있으면 그 사진을 중심으로 구성하고 대표사진으로 쓴다
- 현장 메모: 한두 줄이라도 있으면 반드시 본문 일화로 살린다
- 주제 선택 시 계절·시기(방풍, 결로, 동파, 장마 곰팡이 등) 생활 문제를 한두 주 앞당겨 고르면 홈피드 관심사와 잘 맞는다

## 2. 키워드
- 검색량 큰 대형 키워드(예: "싱크대 경첩") 단독은 피하고, 검색 의도가 분명한 롱테일로 잡는다 (예: "싱크대 문짝 처짐 경첩 조정")
- 핵심 키워드는 제목 앞쪽, 첫 문단, 소제목 1~2곳에 자연스럽게 넣는다. 억지 반복 금지

## 2-1. 용어 확인 (필수)
업계 용어나 번역어를 그대로 쓰지 않는다. 글에 쓸 부품·공구·자재 이름은 **작성 전에 반드시 웹에서 실제 쓰임을 확인**한다.
- 확인 순서: ① 쇼핑몰 상품명(G마켓·옥션·쿠팡·11번가 검색 결과) ② 철물점·제조사 판매 페이지 ③ 시공·DIY 블로그
- 확인한 용어를 둘로 나눠 정리한다
  - **소비자 용어**: 쇼핑몰 상품명과 일반 블로그에서 반복해서 보이는 말 (예: 씽크경첩, 아웃도어, 인도어, 35파이, 15T, 댐퍼)
  - **업계 용어**: 시공자·제조사 자료에만 나오는 말 (예: 아웃셋, 인셋, 오버레이)
- 제목·소제목·본문은 **소비자 용어를 기본**으로 쓴다. 업계 용어는 처음 나올 때 괄호로 한 번만 덧붙인다 (예: "인도어(인셋)")
- 상품명이나 블로그에서 쓰이는 걸 확인하지 못한 말은 **쓰지 않는다** (예: 일자·반곡·대곡처럼 번역해서 만든 말)
- 같은 뜻의 표기가 여러 개면(씽크경첩·싱크대경첩) 검색에 많이 보이는 쪽을 제목에, 나머지는 본문·태그에 넣는다
- 이름보다 넓게 쓰이는 제품은 실제 사용처를 본문에 밝힌다 (예: 씽크경첩은 옷장·장롱·신발장·붙박이장·욕실장에도 쓰임)
- 웹 검색을 쓸 수 없는 환경이면 확인 못 한 용어를 쓰지 말고, 출력 끝에 "용어 미확인"이라고 적는다

## 3. 제목 5안
아래 공식에서 서로 다른 5개를 만들고, 추천 1개에 이유를 한 줄 단다. 0단계 분석이 있으면 상위 글 제목과 겹치지 않으면서 더 구체적인 쪽을 고른다.
1. 증상 + 의외의 해결: "싱크대 문이 처졌다면, 경첩 나사 하나만 돌려보세요"
2. 비용 앵커: "출장비 5만 원 아끼는 방문 끌림 셀프 수리"
3. 현장 고백: "가구 시공하는 사람이 집에서는 이것만 고쳐 씁니다"
4. 숫자·체크리스트: "기사님 부르기 전 5분 점검 7가지"
5. 판단형: "이건 셀프로, 이건 무조건 업체로 (경첩 편)"

규칙:
- **검색 + 홈피드 겸용 구조**: 앞부분은 핵심 키워드(검색용), 뒷부분은 손해·실수·숫자로 궁금하게(홈피드 클릭용). 예: "방풍비닐 치고 곰팡이 핀다? 붙이기 전 결로·테이프·대피로 확인"
- 제목이 약속한 내용은 본문에 반드시 있어야 한다. 낚시성 제목·과장 수치 금지 (신뢰와 노출을 같이 잃음)
- 경력 연수 등 사실 정보는 사용자가 준 것만 쓴다. 모르면 "가구 시공하는 사람"처럼 일반화
- 모바일에서 잘리지 않도록 핵심이 앞 20자 안에 오게, 전체 45자 이내

## 4. 홈피드 썸네일 (대표사진)
홈피드에서는 사진이 제목보다 먼저 보인다. 네이버는 글의 **첫 번째 이미지**를 대표사진으로 쓰므로, 첫 이미지를 썸네일로 만든다.
- **사진**: 실제 작업 사진이 있으면 그것을 쓴다. 없으면 AI 사진을 쓰되 "AI 티"가 나지 않게 한다
  - 이 글이 해결하는 **문제 장면(before 상태)** 하나: 결로 맺힌 창, 처진 문짝, 벌어진 틈 등
  - 한국 아파트 실내를 휴대폰으로 대충 찍은 듯한 구도: 살짝 기운 프레임, 섞인 실내 조명, 먼지·흠집·생활 물건이 가장자리에 보임
  - 피할 것: 쇼룸처럼 깔끔한 연출, 완벽한 대칭, 광택 나는 3D 렌더 느낌, 과한 배경 흐림, HDR, 사람 얼굴 클로즈업
  - 화면 가운데는 비교적 단순하게 둔다(글자가 올라감). 사진 속 글자는 넣지 않는다
- **문구**: 사진 위 가운데에 큰 글자 2줄, 줄마다 4~11자. 둘째 줄은 노란색으로 강조
  - 손해·실수·숫자로 궁금하게, 사실만. 제목을 그대로 반복하지 않는다
  - 예: "방풍비닐 붙였는데 / 곰팡이가 핀다?", "경첩 나사 1개로 / 처진 문 끝"
- 정사각형(1080×1080)으로 만들고 글자는 가운데 띠 안에 둔다 (홈피드가 정사각형·가로형 어느 쪽으로 잘라도 보이게)
- 문구 2안을 내고 추천 1개를 고른다
- 자동화 프로그램(woodenjoy-autopilot)에서는 이 썸네일이 자동으로 만들어진다(hero_prompt + thumb_text → hero.jpg, 원본은 hero_raw.jpg)

## 5. 본문 구조
1. **첫 3줄 훅**: 독자가 겪는 손해·실수 장면을 그대로 짚고("싱크대 문이 살짝 내려앉아 닫을 때마다 걸리시죠?"), 이 글을 읽으면 얻는 것과 결론 힌트를 준다. 날씨·인사·일상 이야기로 시작하지 않는다. 홈피드에서 들어온 독자가 첫 화면에서 나가지 않게 하는 부분이다
2. **결론 먼저**: 한 문단으로 답을 먼저 준다 (요약 인용구)
3. **대표사진(썸네일)**: 결론 문단 바로 뒤, 글의 첫 이미지로
4. **목차**: 소제목 3~5개 미리 보여주기
5. **질문형 소제목** 3~5개, 문단은 2~3문장으로 짧게 (모바일 기준)
6. **표 1개 이상**: 종류 비교, 셀프/업체 판단, 필요한 공구 등
7. **체크리스트 1개**: 중간쯤에 "사기 전/하기 전 확인할 것" 같은 체크리스트를 넣어 끝까지 읽게 한다
8. **현장 일화 1개 이상** (팁 인용구): "현장에서 가장 많이 받는 질문은…", "이렇게 하다 문짝을 망가뜨려 연락 오는 경우가 많아요". 사용자 메모가 있으면 그것을 우선 사용. 지어낸 구체적 사건(날짜·고객·장소)은 만들지 않는다
9. **0단계에서 찾은 "상위 글이 빠뜨린 내용"**을 소제목 하나로 반드시 다룬다
10. **마무리**: 3줄 요약 → **독자에게 묻는 질문 1개**(댓글 유도, 예: "여러분 집 창문은 어떤 타입인가요? 댓글로 알려주시면 맞는 방법 알려드릴게요") → 다음 글 예고 1줄 → "직접 하기 어려우면 우드엔조이로 문의 주세요" 1줄

권장 분량: 공백 포함 약 2,000~3,500자. 0단계 분석이 있으면 상위 글 평균 분량을 참고하되 내용이 끝나면 늘리지 않는다. korean-character-count 스킬을 쓸 수 있으면 완성 후 글자 수를 확인해 출력에 적는다.

## 6. 글 꾸미기 (스마트에디터 기능만 사용)
네이버는 CSS를 받지 않으므로, 사용자가 스마트에디터에서 바로 따라 할 수 있도록 본문에 아래 표시를 넣는다. 색은 myinfobay와 같은 계열(초록 #2f6b57, 연초록 #edf4f1, 연주황 #fbf3e4, 연분홍 #fbeeec)을 쓴다.
- `[인용구-요약] … [/인용구]`: 결론·요약. 스마트에디터 인용구(말풍선 또는 박스 스타일)로 넣는다. 글당 1개
- `[인용구-팁] … [/인용구]`: 현장 일화. 요약과 다른 인용구 스타일(세로줄 등). 글당 1~2개
- `[형광] 문장 [/형광]`: 핵심 문장 배경색(연주황) 강조. 글당 2~3개만
- **굵게**: 소제목과 키워드 위주. 문단 전체를 굵게 하지 않는다
- 표: 단순 표로 쓰고, 아래에 `[표 서식: 머리줄 배경 초록·흰 글씨]` 한 줄을 단다. 항목이 많아 복잡한 표는 `[표 이미지 후보]`로 표시해 Canva 이미지로 대체할 수 있게 한다
- 소제목 사이에는 `[구분선]`을 넣어 모바일에서 단락이 나뉘어 보이게 한다

## 7. 이미지 자리 표시
본문 중 이미지가 들어갈 곳을 표시한다.
- 첫 이미지: `[대표사진: 문제 장면 묘사 / 문구: 첫 줄 / 둘째 줄]` (4단계 기준)
- 실사진이 있으면 `[사진: 설명]`
- 없으면 `[이미지 자리: 무엇을 그릴지]` — 경첩 구조, 규격표, 판단 순서도 등. 도식은 설명용이며 실제 시공 사진처럼 보이게 만들지 않는다
- 다른 사이트·제조사 사진, 경쟁 글의 사진은 쓰지 않는다

## 8. 금지 사항
- 광고(애드포스트) 클릭을 유도하는 문구 일체
- myinfobay.com 글과 같은 문장 재사용 (네이버 유사문서로 검색 제외 위험). 같은 주제라도 이 블로그는 "현장 기록·경험" 각도로 쓴다
- 경쟁 글 문장 베끼기 (패턴만 참고)
- 외부 링크는 글당 최대 1개 (myinfobay 가이드로 연결할 때만). 쿠팡 파트너스 링크는 별도 규칙(대가성 문구 1회, 눈에 띄게)
- 전기·고소 작업: "차단기 내리기·검전 확인"과 "여기부터는 전문가" 경계를 반드시 명시
- 출처 없는 통계·가격. 가격을 쓰면 "2026년 ○월 기준, 지역·조건에 따라 다름"을 붙인다
- 썸네일·제목에서 본문에 없는 내용 약속하기, 공포 조장 과장

## 9. 출력 형식
1. 경쟁 글 분석 요약 (5줄 이내, 또는 "이 환경에서는 생략")
2. 키워드 (메인 1 + 보조 2~3)
2-1. 용어 근거: 소비자 용어 / 업계 용어 / 확인 못 해서 뺀 용어 (각각 한 줄)
3. 제목 5안 + 추천 1개와 이유
