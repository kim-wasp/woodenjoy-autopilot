# 사장님 현장 경험 기록

글에 "현장에서 보면", "고객님 집에 가 보면" 같은 **경험담**을 쓰려면 여기 확인된 기록이 있어야 해요.
Claude는 경험을 지어내지 않아요. 기록이 없으면 경험담 없이 정보로만 써요.

새 기록은 아래 형식으로 추가해요. `확인: 사장님` 줄이 있어야 글에 쓸 수 있어요.
(승인 요청 때 Claude가 "이 문장 맞나요?" 하고 묻고, 사장님이 맞다고 하면 이 줄을 붙여요)

```
## E001 짧은 제목
- 상황: 어떤 집/가구에서
- 한 일: 무엇을 했나
- 이유: 왜 그렇게 했나
- 독자에게: 이 경험이 독자에게 주는 판단 기준 한 줄
- 글에 쓸 수 있는 문장: "…"
- 확인: 사장님 2026-10-23
```

## E001 집 싱크대 경첩은 대부분 아웃도어
- 상황: 싱크대 경첩 교체 현장
- 한 일: 문을 닫고 옆판이 보이는지로 아웃도어/인도어를 구분
- 독자에게: 사기 전에 문 닫고 옆면부터 보면 된다
- 글에 쓸 수 있는 문장: "현장에서 보면 집에 있는 싱크대는 대부분 아웃도어예요."
- 확인: 사장님 2026-10-23

## E002 겨울 현관문 덜 닫힘 문의 (사장님 확인 대기)
- 상황: 날이 추워질 때 현관문이 끝까지 안 닫힌다는 이야기
- 한 일: (사장님이 직접 도어클로저 속도를 조절해 주신 적이 있는지 확인 필요)
- 독자에게: 겨울에 문이 덜 닫히면 교체 전에 속도 나사부터 본다
- 글에 쓸 수 있는 문장(후보): "날이 추워지면 현관문이 끝까지 안 닫힌다는 이야기를 자주 듣는데, 대부분 도어클로저 속도 조절로 해결돼요."
- 상태: 사장님 확인 대기 (2026-10-26 글에는 쓰지 않음)

## E003 서랍레일 교체 문의 때 먼저 하는 말 (사장님 확인 대기)
- 상황: 서랍이 덜컹거리거나 레일이 부러져 새 레일을 사려는 문의
- 한 일: (사장님이 실제로 기존 레일 길이·옆 틈부터 재 보라고 안내하시는지 확인 필요)
- 독자에게: 레일을 사기 전에 기존 레일 길이와 옆 틈부터 잰다
- 글에 쓸 수 있는 문장(후보): "서랍레일 교체 문의를 받으면 제일 먼저 기존 레일 길이부터 재 보시라고 해요. 길이만 맞아도 다시 사러 가는 일이 거의 없어요."
- 상태: 사장님 확인 대기 (2026-10-30 글에는 쓰지 않음)
