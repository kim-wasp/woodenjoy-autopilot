# 우드엔조이 오토파일럿

일·화·목 저녁마다 Claude가 **제목 선정 → 네이버 글 → 카드뉴스 이미지 → 글 점검 → 이미지 점검 → 인스타 캡션 → 스레드 글**까지 준비해서 승인 요청을 보내요. 휴대폰에서 확인하고 **병합(승인)** 을 누르면 인스타·스레드가 **각자 사람들이 많이 보는 시간**에 자동으로 올라가요.

네이버 블로그는 공식 글쓰기 API가 없어요. 그래서 **uplika**(크롬 확장)가 사장님 컴퓨터의 크롬에서 대신 편집기를 열고 글을 채워 올려요. 처음 2주는 **비공개**로 올라가니, 네이버 앱에서 확인하고 공개로 바꾸면 돼요. uplika를 안 쓰면(`settings.json` → `naver.via: "manual"`) 예전처럼 붙여넣기용 원고만 받아요.

## 흐름

```
[Claude 예약 실행 · 일·화·목 저녁 8시]
  1 제목 선정(검색·검증) → 2 글 → 3 이미지 → 4 글 점검 → 5 이미지 점검 → 6 인스타 → 7 스레드
  → GitHub에 승인 요청(PR) + 휴대폰 알림
[GitHub 자동 실행 · 승인 요청 때]
  점검 한 번 더 → 네이버에 비공개로 업로드 (uplika, 크롬이 켜져 있어야 함) → PR에 업로드 예정 시간 댓글
[사장님 · 자기 전]
  네이버 앱에서 비공개 글 확인 → PR에서 '병합' 누르기 (그 뒤는 전부 자동)
[다음 날 · 월·수·금]
  07:00  네이버  ← 비공개로 올려 둔 글을 자동으로 공개로 전환 (같은 주소)
  12:30  스레드 (본문·댓글 2개, 마지막 댓글에 네이버 글 링크)
  21:00  인스타 캐러셀
  (GitHub가 30분마다 확인해서 시간이 된 것만 올려요. 올리기 직전 점검을 한 번 더 해요)
```

## 업로드 시간표 (바꾸려면 `config/settings.json` → `slots`)

| 플랫폼 | 요일 | 시간 | 이렇게 정한 이유 |
|---|---|---|---|
| 네이버 블로그 | 월·수·금 | 07:00 | 검색으로 들어오는 글이라, 조회가 많은 오후·밤 전에 미리 올려 검색에 잡힐 시간을 벌어요 |
| 스레드 | 월·수·금 | 12:30 | 평일 낮(점심 무렵) 반응이 좋다는 집계가 많아요. 네이버 글이 먼저 올라가 있어 링크가 바로 연결돼요 |
| 인스타 | 월·수·금 | 21:00 | 퇴근 후 쉬는 시간. 팔로워 100명이 넘으면 인사이트의 '팔로워 활동 시간'으로 바꿔요 |

- 시간은 모두 한국 시간이에요. 승인이 늦어져 시간이 지나면 **다음 차례**(예: 수요일)에 올라가요. 3시간 넘게 놓친 시간에 억지로 올리지 않아요
- GitHub 예약 실행은 몇 분~수십 분 늦을 수 있어요
- 이 시간은 공개된 일반 자료 기준의 출발점이에요. 한두 달 뒤 **네이버 블로그 통계(시간대별 조회수)**, 인스타 인사이트, 스레드 조회수를 Claude에게 보여 주면 사장님 계정에 맞게 바꿔요
- 글 하나가 언제 올라갈지 보기: `python3 tools/schedule.py show posts/<글폴더>`

2주 뒤(`config/settings.json`의 `auto_publish`를 `true`로 바꾸면) 점검을 통과한 글은 승인 없이 바로 올라가요.

## 처음 한 번만 하는 설정

### 1. GitHub
1. github.com 가입 (이미 있으면 건너뛰기)
2. 새 저장소 만들기: 이름 `woodenjoy-autopilot`
   - **Public(공개)** 으로 만들어요. 인스타·스레드 공식 API는 카드 이미지를 인터넷 주소에서 가져가기 때문이에요. 토큰 같은 비밀 정보는 Secrets에 따로 보관돼서 공개돼도 안전해요
3. 이 폴더의 파일을 모두 올리기
4. claude.ai 설정 → 연결(Connectors)에서 GitHub 연결 → Claude가 이 저장소에 승인 요청을 올릴 수 있게 돼요

### 2. uplika (네이버 블로그 업로드 전용)
1. uplika.com 가입 (구글·깃허브·이메일, 카드 등록 없음)
2. 연결 → 새 연결 → **Naver Blog** → 크롬 확장 「uplika 업로드 도우미」 설치 → **네이버에 로그인해 둔 그 크롬**에서 「네이버 블로그 연결」 → 채널 카드에 「정상」「확장 켜짐」이 보이면 끝
4. 대시보드에서 **API 키** 발급 → GitHub Secrets 에 `UPLIKA_API_KEY` 로 저장
5. `config/settings.json` 의 `naver.category` 를 실제 블로그 카테고리 이름으로 (기본값 "셀프 집수리")

알아둘 점
- 네이버 업로드는 **크롬이 켜져 있어야** 나가요. 꺼져 있으면 켜질 때까지 최대 7일 기다려요
- 무료는 월 20건이에요 (베타 기간은 전부 무료). 네이버만 주 3회면 월 13건 정도라 무료 한도 안이에요
- 네이버는 "매크로 등 어뷰징"을 제재한다고 밝혔어요. 확장 프로그램이 대신 입력하는 방식이 여기에 해당하는지는 명확하지 않으니, **주 3회·직접 확인한 글만** 올리는 지금 규칙을 지켜 주세요
- 카드 이미지는 Claude가 만든 것이라 네이버 「AI 활용」 표시를 켜서 올려요 (사진 줄 끝 `{.ai}` — uplika 확장 **0.7.3 이상**이어야 해요)
- 크롬이 꺼져 있어 '대기'인 글은 30분마다 상태를 다시 확인해요. 네이버 주소가 생겨야 스레드가 올라가요
- 네이버 업로드가 **실패**하면(예: 「발행이 잠시 제한」) 자동으로 다시 시키지 않아요. 같은 글이 두 번 올라가는 걸 막기 위해서예요. 스레드·인스타는 블로그 홈 링크로 예정대로 올라가요
- 막히면 Claude에게: "uplika로 내 네이버 블로그 확장이 지금 켜져 있는지, 기다리는 글이 있는지 확인해줘"

### 2-2. 검색량 조회 (네이버 검색광고 키워드 도구, 무료)
제목·키워드를 고를 때 **실제 월간 검색량**을 보려고 네이버 공식 API를 써요. 광고비를 쓰지 않아도 키 발급과 조회는 무료예요.
1. searchad.naver.com 에서 광고주 계정 가입 (네이버 아이디로, 사업자 정보 입력. 광고를 집행하지 않아도 돼요)
2. 검색광고 시스템 → **도구 → API 사용 관리** → 네이버 검색광고 API 서비스 신청 → 키 발급
3. 화면에 나온 세 가지를 GitHub Secrets 에 저장: **액세스라이선스** → `NAVER_AD_API_KEY`, **비밀키** → `NAVER_AD_SECRET_KEY`, **CUSTOMER_ID** → `NAVER_AD_CUSTOMER_ID`
4. (선택) 블로그 글 수도 보고 싶으면 developers.naver.com → 애플리케이션 등록 → '검색' API → `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
5. GitHub → Actions → **키워드 조사** → Run workflow 로 한 번 돌려 보고 `topics/keywords.json` 이 생기면 끝. 이후 일·화·목 19시에 자동으로 갱신돼요

알아둘 점
- 검색량은 네이버 광고 시스템이 집계한 최근 한 달 조회수예요. 10 미만은 "<10"으로 나와요
- 화면의 '경쟁 정도'는 **광고 입찰 경쟁**이에요. 블로그 상위 노출 난이도가 아니에요
- 조회 주기를 일주일에 3번, 키워드 20개 정도로 잡아서 호출 제한에 걸리지 않게 했어요

### 2-1. 인스타·스레드는 Meta 공식 API로 직접 올려요 (기본)
`config/settings.json` 의 `social_via` 가 `"meta"` 예요. 아래 3~5를 해요. (나중에 uplika로 합치고 싶으면 `"uplika"` 로 바꾸고 uplika에 인스타·스레드를 연결하면 돼요. 그러면 uplika 월 한도에 같이 잡혀요.)

### 3. 인스타그램 (woodenjoy00, meta 방식)
1. 인스타 앱 → 설정 → 계정 유형 → **프로페셔널 계정**(크리에이터 또는 비즈니스)으로 전환
2. developers.facebook.com 에서 앱 만들기 → "Instagram API" 추가 → **Instagram 로그인 방식(Business Login for Instagram)** 선택
3. 권한: `instagram_business_basic`, `instagram_business_content_publish`
4. woodenjoy00 계정을 테스터로 추가하고 토큰 발급 → **장기 토큰(60일)** 으로 교환
5. 계정 ID(IG_USER_ID)와 토큰(IG_TOKEN)을 GitHub Secrets에 저장

### 4. 스레드 (meta 방식)
1. 같은 Meta 개발자 앱에 "Threads API" 추가
2. 권한: `threads_basic`, `threads_content_publish`
3. 장기 토큰(60일) 발급 → THREADS_USER_ID, THREADS_TOKEN 을 Secrets에 저장

### 5. GitHub Secrets (저장소 → Settings → Secrets and variables → Actions)
| 이름 | 내용 |
|---|---|
| UPLIKA_API_KEY | uplika API 키 (uplika 방식) |
| IG_USER_ID | (선택) 인스타 계정 ID. 없으면 토큰 주인 계정 |
| IG_TOKEN | 인스타 장기 토큰 |
| THREADS_USER_ID | (선택) 스레드 계정 ID. 없으면 토큰 주인 계정 |
| THREADS_TOKEN | 스레드 장기 토큰 |
| NAVER_AD_API_KEY | 검색광고 액세스라이선스 (검색량 조회) |
| NAVER_AD_SECRET_KEY | 검색광고 비밀키 |
| NAVER_AD_CUSTOMER_ID | 검색광고 CUSTOMER_ID (숫자) |
| NAVER_CLIENT_ID / NAVER_CLIENT_SECRET | (선택) 블로그 글 수 조회용 |
| GH_PAT | 토큰 자동 연장용 GitHub 토큰 (Fine-grained, 이 저장소 Secrets 쓰기 권한) |

meta 방식이면 토큰은 매달 1일·15일에 자동으로 연장돼요(`토큰 연장` 워크플로).

### 6. 시험
- 먼저 `python3 tools/publish_naver.py posts/<글폴더> --dry-run`, `python3 tools/publish.py posts/<글폴더> --dry-run` 으로 무엇이 올라갈지 확인해요
- 첫 실제 업로드는 네이버 **비공개**로 한 편 올려 보고, 네이버 편집기에서 소제목·인용구·표·이미지가 제대로 들어갔는지 눈으로 확인해요

## 점검 기준 (자동)

**이미지** (`tools/render_cards.js`)
- 모든 글자 실제 크기 36px 이상 (그림 속 글자 포함)
- 글자 넘침·잘림, 의도하지 않은 줄바꿈, 블록 겹침, 빈 칸
- 도형 밖으로 삐져나온 글자, 계정명 자리 침범, 아래 빈 공간 과다
- 너무 비슷한 장, 여러 장에 반복된 문장, 확인 안 된 용어

**글** (`tools/check_text.py`)
- 공통: 근거 없는 과장 표현(무조건·완벽 정리·BEST 등), 남은 작업 메모([확인 필요] 등), **확인 안 된 경험담**("현장에서 보면" 등은 `topics/experience.md`에 사장님 확인 기록이 있어야 통과)
- 브리프(독자·질문·핵심 답·다루지 않을 것·다음 행동)가 있어야 하고, 핵심 키워드를 너무 많이 반복하면 실패
- 네이버: 1,800~3,800자, 첫 문장 인사 금지, 요약·현장 팁·표·소제목 3개 이상, 링크 1개 이하, 광고 유도 금지, 가격엔 기준일, 예전 글과 25% 이상 겹침 금지, 제목 키워드 위치·길이
- 인스타: 2,200자 이하, 해시태그 5개 이하, 링크 금지, 첫 줄 60자 이하, 카드 점검 통과
- 스레드: 각 500자 이하, 링크는 마지막 댓글에만, 주제 태그 1개 이하

자동 점검 뒤에 Claude가 카드 전체를 눈으로 다시 확인해요(그림이 제목과 같은 말을 하는지 등 코드로 못 잡는 부분).

## 폴더
```
config/   brand.json(계정·색), terms.json(확인된 용어·금지 용어), settings.json(자동 승인·업로드 시간표 등)
posts/    글마다 폴더: post.json, naver.md, cards.json, cards/*.jpg
tools/    render_cards.js(카드+이미지 점검), check_text.py(글 점검), naver_markdown.py(네이버 형식 변환),
          publish_naver.py(네이버 업로드), publish.py(인스타·스레드 업로드), schedule.py(플랫폼별 업로드 시간), keywords.py(검색량 조회)
topics/   backlog.md(글감), used.json(쓴 글), seed_keywords.txt·keywords.json(검색량), experience.md(사장님 확인 현장 경험), performance.md(발행 후 성과)
AUTOPILOT.md  Claude가 따르는 전체 순서
```
